Hexagonal Shop API (Go) — v0.1.0

ลองยิง API ได้เลย: /swagger-ui/ (Swagger UI, self-hosted)

สเปกฉบับเต็ม (OpenAPI 3): /swagger/openapi.yml — นำไปเปิดใน ReDoc / Postman ได้โดยตรง

Endpoints

Endpointคำอธิบายผลลัพธ์
POST /api/customers สมัครสมาชิกใหม่ 201 · 400 (payload ผิดรูป) · 409 (อีเมลซ้ำ) · 429
GET /api/products/category/{categoryId} ดูสินค้าตามหมวดหมู่ (เสิร์ฟจาก cached adapter) 200 (array ว่างได้) · 429
GET /health health check (docker/k8s probe) 200 · 503

ตัวอย่าง

curl -i -X POST localhost:8090/api/customers \
  -H 'Content-Type: application/json' \
  -d '{"id":"c100","email":"bird@shop.com","name":"Bird"}'

curl -s localhost:8090/api/products/category/c1
